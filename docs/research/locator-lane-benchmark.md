# Locator Lane Benchmark

This file is generated by `npm run benchmark:locator`. Run it with sidecar and Calorix images configured to populate lane counts, per-image coverage, elapsed times, and label stability across locator input resolutions.

The benchmark now runs dimensions sequentially. Do not compare timings from concurrent locator calls; concurrent calls contend for the local sidecar worker and make the elapsed times meaningless.

Default dimensions:

```powershell
$env:UI_DIFF_LOCATOR_BENCHMARK_DIMENSIONS = "600,900,1200"
```

The script also writes `docs/research/locator-lane-benchmark.json` with the full structured result. If one dimension times out, the script preserves completed lower-dimension evidence and records the failed dimension as `timeout`.

## Current Result

`needs_live_data` — run `npm run benchmark:locator` with `UI_DIFF_LIVE_EXPECTED_IMAGE`, `UI_DIFF_LIVE_ACTUAL_IMAGE`, and `LOCATEANYTHING_SIDECAR_URL` set to populate this file.

## Default Parser Policy

Default enabled lanes:

1. `cv_components`
2. `ocr_text` when an OCR engine is installed
3. `locateanything`
4. `omniparser` only when explicitly enabled and license accepted
5. `yolo_ui` only when a local model path is configured

Release selection rule: Calorix bounded and full live gates must pass with the highest locator dimension that fits the configured sidecar budget. `600` is a timeout workaround, not a quality default.
